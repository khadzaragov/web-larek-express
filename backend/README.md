# Черновые заметки по запуску

- Локально гоняю MongoDB без докера (`mongod --dbpath ~/data/weblarek`), поэтому в `.env` прописал `mongodb://127.0.0.1:27017/weblarek`.
- Если тесты падают по таймауту, стоит просто перезапустить — первый запуск `mongodb-memory-server` иногда долго прогревается.
- Напоминание себе: как только появится загрузка файлов, нужно проверить, что `public/images` действительно раздаётся, а не только `gitkeep` лежит.
